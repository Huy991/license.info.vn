# license.info.vn

Trang giới thiệu và tải về các phần mềm văn phòng cho Windows, giao diện tiếng Việt:

- **InvoiceCheck**: kiểm tra hóa đơn điện tử từ PDF và XML
- **InvoiceViewer**: xem hóa đơn XML, chuyển sang PDF
- **PdfTool**: bộ công cụ PDF
- **ScanApp**: quét tài liệu tự động, tự đặt tên file

Trang web là một file `index.html` tĩnh, chạy bằng GitHub Pages. File cài đặt nằm ở mục [Releases](https://github.com/Huy991/license.info.vn/releases); nút tải trên trang trỏ tới `releases/latest/download/<tên file>`, nên khi phát hành bản mới chỉ cần đính kèm file cùng tên.
